# Admin Android App

Native Android application for store administrators to manage inventory, process orders, and view analytics.

## Features
- Product catalog management
- Inventory control and monitoring
- Order processing and fulfillment
- Sales analytics and reporting
- Staff management
- Multi-role access control

## Technical Details
- **Package**: `com.grocery.admin`
- **Min SDK**: API 24 (Android 7.0)
- **Target SDK**: API 34 (Android 14)
- **Architecture**: MVVM with Clean Architecture
- **UI**: Jetpack Compose
- **Distribution**: Google Play Store (Internal Testing)

## Setup
1. Open in Android Studio
2. Sync Gradle files
3. Configure API keys in `local.properties`
4. Run on device or emulator
