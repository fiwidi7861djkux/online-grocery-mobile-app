# Delivery Android App

Native Android application for delivery personnel to accept orders, navigate to locations, and track performance.

## Features
- Order acceptance and management
- Google Maps integration with navigation
- Delivery status updates
- Proof of delivery capture
- Earnings and performance tracking
- In-app communication

## Technical Details
- **Package**: `com.grocery.delivery`
- **Min SDK**: API 24 (Android 7.0)
- **Target SDK**: API 34 (Android 14)
- **Architecture**: MVVM with Clean Architecture
- **UI**: Jetpack Compose
- **Distribution**: Google Play Store (Internal Testing)

## Setup
1. Open in Android Studio
2. Sync Gradle files
3. Configure API keys in `local.properties`
4. Run on device or emulator
